# Gospel Advance Acts 4:29 Logo

Approved source supplied by Andrew on October 3, 2026:
`gospel-advance-acts-logo-original.png`.

`gospel-advance-acts-logo.png` is a transparent horizontal header adaptation,
prepared from that source using image generation. It places the flame to the
left and retains the ministry name and Acts 4:29 reference. The original remains
available unchanged; the adaptation is not a vector master.

Shared branding in `assets/site.css` uses this horizontal asset. On dark
surfaces, the SVG color filter in `assets/icons/logo-on-dark.svg` changes the
dark lettering to white while retaining a red flame and transparent background.
The same source geometry is used for both themes.
